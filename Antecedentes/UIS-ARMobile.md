# UIS-ARMobile

**Ámbito:** Departamental · **Año:** 2013

- **Autores:** Carlos Enrique Díaz Aranda y Gabriel Fernando Pérez Arenas (UIS). Directores: Hernán Porras Díaz y Óscar Alberto Rodríguez Cuadros.
- **Qué es:** app de **realidad aumentada** en Java para tabletas Android; GPS + acelerómetro + magnetómetro; coordenadas sacadas de la API de Google Maps.
- **Limitaciones:** depende del GPS (falla bajo techo); usa mapas de terceros sin nomenclatura propia; **sin grafo de rutas** (dice dónde queda, no cómo llegar).
