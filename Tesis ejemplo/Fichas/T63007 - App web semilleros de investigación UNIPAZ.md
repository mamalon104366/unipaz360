# T63007 · App web semilleros de investigación UNIPAZ

**Título:** APLICACIÓN WEB PARA LA GESTIÓN DE LOS PROYECTOS DE INVESTIGACIÓN DE GRUPOS Y SEMILLEROS DE INVESTIGACIÓN DEL INSTITUTO UNIVERSITARIO DE LA PAZ  
**Autores:** Isnardo Galvis Rangel; Juan Pablo Jerez Noriega  
**Director:** [[Edwin Durán Blandón]]  
**Modalidad:** [[Proyecto de grado]] · **Año:** 2021  
**Temas:** [[Desarrollo web]] · [[Sistemas para UNIPAZ]]  
**Tecnologías y métodos detectados:** [[PHP]] · [[Galvis Panqueva]] · [[MySQL]] · [[Google Maps]] · [[Incremental]] · [[Laravel]]  
**Relevancia para UniPaz360:** media: Sistema para UNIPAZ con metodología incremental IWeb (Pressman).

## Objetivo general
Implementar una aplicación web para la gestión de proyectos de los grupos y semilleros de investigación del Instituto Universitario de la Paz, utilizando la metodología incremental Iweb de Roger Pressman. 1.2.2.
